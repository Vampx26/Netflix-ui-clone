# Netflix UI Clone 🎬

A responsive Netflix UI Clone built to practice modern frontend development and real world UI implementation. This project focuses on recreating the look and feel of Netflix’s homepage with clean layouts, responsive design, and smooth user experience.

---

## 🚀 Features

- Netflix-inspired homepage layout  
- Responsive design for mobile, tablet, and desktop  
- Clean and reusable UI components  
- Smooth hover effects and transitions  
- Modern layout using Flexbox and Grid  

---

## 🛠️ Tech Stack

- HTML5  
- CSS3    
- Flexbox & Grid  
- Responsive Design  

---

## 📚 What I Learned

- Building real world UI layouts  
- Responsive design principles  
- Structuring clean and maintainable frontend code  
- Improving attention to design details and spacing
